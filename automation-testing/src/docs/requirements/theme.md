# THEME — Sáng / tối

Truy vết phía app: FR-14 · US-03 · ADR-0001.

- **REQ-THEME-01** Mặc định ("Theo hệ") giao diện theo chế độ sáng/tối của hệ điều hành, và đổi ngay khi hệ đổi lúc tab đang mở.
- **REQ-THEME-02** Nút "Đổi sáng / tối" ở header đổi giao diện đang hiện sang chế độ còn lại ở **mỗi** lần bấm, ghi đè hệ điều hành theo cả hai chiều.
- **REQ-THEME-03** Lựa chọn rõ ràng (Sáng hoặc Tối) thắng hệ điều hành và còn nguyên sau khi tải lại trang.
- **REQ-THEME-04** Cài đặt có ba lựa chọn Theo hệ / Sáng / Tối, đánh dấu đúng lựa chọn hiện tại, và mỗi lựa chọn áp dụng ngay.
